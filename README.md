# My portfolio

A personal portfolio website showcasing my projects, resume, skills, and background, built with Next.js.

![](./assets/image.png)

# View it live here: [click!](https://botwinka.dev)

Features:

- Seeing my projects
- Downloading my resume
- Reading about me
- Good SEO 


```bash
bun i
```

- Start dev server:

```bash
bun dev
```

Tech used:

- Next.JS
- Vercel
- Biome
- TailwindCSS
